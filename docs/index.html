非官方 App · 學生自製

把北教大校務系統與 Moodle，
裝進一個原生 App。

NTUE unofficial 整合國立臺北教育大學 iNTUE 校務系統與 Moodle 教學平台， 課表、作業、成績、請假、行事曆倒數，通通不用再開瀏覽器慢慢找。

查看 GitHub 專案 它怎麼運作？ 取得支援

本 App 為在學學生個人開發之非官方應用程式，與國立臺北教育大學無任何隸屬或合作關係。

🏠

首頁總覽

下一堂課倒數、今日課表、待繳作業、學期倒數，一眼看完。

📅

課表與行事曆

個人週課表、公開課表查詢，一鍵匯入校園行事曆到系統行事曆。

📝

作業與公告

Moodle 作業依課程分組顯示繳交狀態，課程公告不漏看。

📊

成績

單學期成績，以及自動彙總累積學分與加權 GPA 的歷年成績總表。

📄

請假 / 在學證明 / 修業進度

請假明細與線上申請、中英文在學證明 PDF、修業進度檢核表 PDF。

📱

Widget / Live Activity

桌面小工具與課程動態，上課前主動在鎖定畫面與靈動島提醒。

沒有後端伺服器

本 App 沒有自己的伺服器，所有功能都是在你的裝置上， 以你的登入身分直接連線至學校官方系統擷取資料。帳號密碼只加密存在裝置的 Keychain，開發者無法存取任何帳號或校務資料。

想知道它實際上怎麼登入、怎麼抓資料，以及為什麼開發者「無法」看到你的帳密， 請見運作原理與資安說明；法律文件請見隱私權政策。
