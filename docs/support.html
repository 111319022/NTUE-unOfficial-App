1. 登入失敗 / 顯示資料過舊

  • 先確認能否用同一組帳密，直接在瀏覽器登入校園入口網（protocol.ntue.edu.tw）—— 如果連網頁版都無法登入，通常是帳密或校方系統本身的問題，需聯絡教務處／資訊中心，而非本 App。
  • App 內在各清單頁面下拉可「下拉重新整理」強制重抓最新資料；部分過去學期資料為離線快取，屬正常設計。
  • 若確定帳密正確但 App 仍無法登入或資料明顯錯誤，請到 GitHub 開 Issue，並註明使用的 iOS 版本與大致操作步驟（請勿在 Issue 內附上你的帳號密碼）。

2. 功能建議 / 想要的頁面還沒支援

本 App 由學生個人維護，功能會依開發時間逐步擴充。歡迎在 GitHub Issues 提出想要的功能（例如某個校務系統頁面尚未整合），會盡量評估加入。

3. 資料正確性

App 內所有課表、成績、作業等資料都即時取自學校官方系統（iNTUE 校務系統、Moodle），本 App 僅負責呈現，不會修改任何資料。若 App 內容與官方系統顯示不一致，請一律以官方系統為準，並回報讓開發者確認是否為解析邏輯的問題。

4. 隱私相關問題

本 App 沒有後端伺服器，帳密只存在你裝置的 Keychain。詳細說明請見隱私權政策。
